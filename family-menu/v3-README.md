# 🧋💕 给她点奶茶 · 专属外卖单

**你在异地/校外，也能立刻知道她「想喝什么、加什么料、送到哪」——挑好直接生成订单文字，复制给外卖软件或代拿的同学就行。**

粉色主题 + 爱心动效，单文件网页，不用装 App、不用注册、数据全在自己手机里。

## 在线地址

**https://hzj-lesson.github.io/family-menu/**

手机浏览器打开，加到主屏幕就跟 App 一样。默认收货地址已设为**西华师范大学华凤校区二期**。

## 功能

| 功能 | 说明 |
|---|---|
| 🧋 **15 个奶茶/咖啡品牌** | 蜜雪冰城、霸王茶姬、茶百道、古茗、沪上阿姨、CoCo、喜茶、奈雪、书亦、一点点、益禾堂、甜啦啦、7分甜、瑞幸、星巴克，共 60+ 款招牌，价格为参考价可改 |
| 🍬 **规格选择** | 甜度 / 温度 / 杯型 / 加料，加料和大杯自动算加价，还能写「想对她说」的一句话 |
| 🛒 **购物车** | 同品同规格自动合并，加减数量实时合计 |
| 📋 **一键复制下单** | 生成排版好的订单文字（地址/电话/每杯规格/备注/合计），粘到美团备注或直接发给代拿的人 |
| 📍 **收货信息** | 校区 + 楼栋门牌 + 收货人 + 电话，下单自动带上 |
| 🔁 **再来一单** | 历史订单一键放回购物车 |
| ⚙️ **管理** | 品牌/饮品增删改、品牌开关（不配送的关掉）、首页文案自定义、JSON 备份导入导出 |
| 💕 **粉色心动** | 玫瑰粉渐变、加购飘爱心、下单爱心雨、心跳 logo |

## 怎么用（点外卖场景）

1. **第一次用**：「管理」→ 填她的楼栋门牌和电话；在美团/饿了么搜一下哪些品牌能送到华凤校区二期，**送不到的把开关关掉**（品牌管理里一键隐藏）
2. **平时点单**：选品牌 → 饮品旁点 ＋ → 挑甜度/冰度/加料 → 加入购物车
3. **下单**：去购物车 → 填备注 → 「生成订单 · 一键复制」→ 打开美团/饿了么照着点，或把文字发给帮她带的人

## 外卖小提示（华凤校区二期）

- 校内：二期食堂（李园餐厅）二楼通常有奶茶窗口，下课顺路最省事
- 外卖：多数品牌送宿舍楼下或校门口自提点，**具体配送范围以 App 实际为准**
- 起送价：校园周边常见 20～30 元起送，单点一杯可能凑不够，拼单更划算

## 技术说明

- **单个 HTML 文件，37KB，零依赖**，纯前端
- 数据存浏览器 `localStorage`（键名 `naicha_order_v3`），不上传任何服务器
- 移动端优先，支持 iOS 安全区（刘海屏不遮挡）
- 品牌数据在源码 `PRESET` 数组里，改价格/加品牌直接编辑后重新部署，或在页面「管理」里改

> ⚠️ 数据只存本地浏览器，换设备或清缓存会丢，重要订单先「导出备份」。
