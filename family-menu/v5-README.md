## 三分钟配好（只做一次）

| 步骤 | 做什么 |
|---|---|
| 1 | **你**打开链接 → 「设置」填她的楼栋门牌和电话（默认校区已是西华师范大学华凤校区二期） |
| 2 | 「🔔 通知设置」选一个推送方式、填 key（见下表）→ 保存 → 点「发一条测试」确认手机能收到 |
| 3 | 点「🔗 生成并复制链接」→ **微信发给她** |
| 4 | 她打开链接就是「宝贝的点单页」，地址和你配的推送都已自动带上 |

### 推送方式选哪个

| 方式 | 去哪拿 key | 说明 |
|---|---|---|
| **Server酱 Turbo** | `sct.ftqq.com` 微信扫码登录，复制 SendKey | 推到微信服务号，最省事 |
| **PushPlus** | `pushplus.plus` 微信扫码登录，复制 token | 微信公众号推送，免费 200 条/天 |
| **WxPusher** | `wxpusher.zjiecode.com` 扫码关注应用 | 需要 appToken + UID 两个值 |
| **Bark** | iPhone 装 Bark App，复制地址里的 key | 仅 iOS |
| **不推送** | — | 她点完后复制订单文字发微信给你，一样能用 |

> key 只写不读，存在链接里发给她；最坏情况是有人拿到后给你发垃圾推送，不影响账号安全。

## 她怎么用

1. 顶部选**品类**（奶茶 / 炸鸡汉堡 / …）→ 选**品牌**
2. 菜品右边点 `＋` → 挑规格（套餐？辣度？加薯条？）
3. 购物车 → 点 **「💕 告诉 TA 我想吃」**
4. 配了推送 → 你微信秒收；没配 → 弹窗里一键复制，她粘微信发你

## 你这边（收单箱）

- 推送直接看微信消息就行
- 也可以把她在微信里发给你的订单文字**粘贴进「📥 收单箱」**，点「✓ 已下单」标记
- 底部导航第 3 个「📋 收单箱」= 收进来的订单 + 本机订单记录

## 外卖小提示（华凤校区二期）

- 校内：二期食堂（李园餐厅）二楼通常有奶茶窗口，下课顺路最省事
- 外卖：多数品牌送宿舍楼下或校门口自提点，**具体配送范围以 App 实际为准**
- 起送价：校园周边常见 20～30 元起送，单点一份可能凑不够

## 技术说明

- **单个 HTML 文件，约 66KB，零依赖**，纯前端
- 数据存浏览器 `localStorage`（键名 `naicha_order_v4`），不上传任何服务器
- 品牌数据结构：`[id, 名称, emoji, 品类, [[品名, 价格, 备注],…]]`，在源码 `PRESET` 数组里；品类与规格分别在 `CATS` 和 `SPECS`
- **不同品类用不同规格组**（`SPECS.tea` / `SPECS.burger` / …），新增品类只需加 `CATS` 项 + `SPECS` 项 + 品牌里标品类
- 推送走 `fetch` 直连各服务商（均已开通 CORS），不经任何中转；配置链接把设置 base64 编码放进 URL hash
- 已做旧数据迁移：老版本（品牌无品类字段）会自动补上全量新品类，并保留自定义品牌、推送配置、地址

> ⚠️ 数据只存本地浏览器，换设备或清缓存会丢，重要订单先「导出备份」。
> 两个角色的数据各自存在各自手机上，**不会自动互相同步** —— 她点了什么靠推送/微信告诉你，这是刻意设计（免后端、免注册）。
