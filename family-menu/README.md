# 🍳 家庭点菜单

自建菜单 → 分享给家人 → 他们点单 → 自动生成采购清单。
照着「独家御膳房」的核心玩法做的**网页版**，不用装 App、不用注册、不依赖微信。

## 在线地址

**https://hzj-lesson.github.io/family-menu/**

手机浏览器直接打开，加到主屏幕就跟 App 一样。

## 功能

| 功能 | 说明 |
|---|---|
| 🍽 **菜单管理** | 自定义分类（荤菜/素菜/主食/汤羹/饮品…）、菜名、食材简介、价格、标签、招牌标记 |
| 🖼 **菜品图片** | 可上传照片，自动压缩到 400px（存在浏览器本地，不上传服务器） |
| 🛒 **点单** | 分类浏览、加减数量、购物车实时合计、填名字和备注（口味/忌口） |
| 🧾 **订单** | 按时间倒序，显示谁点了什么、几点点的、有什么备注 |
| 🛍 **采购清单** | 自动汇总所有订单的菜品和数量，一键复制，照着买菜 |
| 🔗 **分享点菜** | 生成链接发给家人，他们打开就能看到你的菜单并点单 |
| 📤 **备份导入导出** | 导出 JSON 备份，换手机/误删可恢复 |

## 两种角色怎么用

**你是厨房主人**（掌勺的）：
1. 打开 → 右上角「厨房」→「菜单」→ 添加菜品
2. 「设置」里改厨房名和公告（比如"今天有大闸蟹～"）
3. 「设置」→「生成分享链接」→ 发到家庭群

**家人朋友**（点菜的）：
1. 点开你发的链接，自动载入你的菜单
2. 选菜、填名字和备注 → 提交

订单存在各自手机本地。家人点完可以在「设置」里复制订单发回给你，你用「粘贴订单码」导入。

## 技术说明

- **单个 HTML 文件，31KB，零依赖**，纯前端
- 数据存在浏览器 `localStorage`（键名 `family_menu_v1`），**不上传任何服务器**
- 分享链接把菜单数据 base64 编码放进 URL hash，不经过服务器
- 移动端优先设计，支持 iOS 安全区

> ⚠️ 因为数据只存在本地浏览器，**换设备或清缓存会丢**。重要菜单记得用「导出备份」存一份 JSON。
> 想要多人实时同步（家人点单你这边立刻看到）需要加后端，纯前端做不到。
